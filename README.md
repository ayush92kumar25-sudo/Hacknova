# EcoPulse - Smart Waste Management & Civic Action System (MVP)  A comprehensive, production-ready Full-Stack Minimum Viable Product (MVP) for centralized municipal and residential waste management, issue reporting, bulk pickup scheduling, complaint milestone tracking, administrator hotspot analytics, and citizen waste segregation awareness.  ---  ## 1. System Architecture Overview  ```                            ┌───────────────────────────┐                           │   Citizens & Admins       │                           │   (Web Client / Mobile)   │                           └─────────────┬─────────────┘                                         │ HTTPS / JSON                                         ▼     ┌──────────────────────────────────────────────────────────────────┐     │                     Presentation Layer                           │     │  - Responsive SPA (HTML5, Modern CSS Variables, Modular Vanilla JS)│     │  - GPS Geolocation Detection & Map Coordinates                   │     │  - Real-time 4-Stage Milestone Tracking Timeline                  │     │  - Interactive "Can I Recycle This?" Search Engine               │     │  - Admin Sanitation Dispatch & Hotspot Metrics Dashboard         │     └───────────────────────────────────┬──────────────────────────────┘                                         │ REST APIs (JWT Bearer Auth)                                         ▼     ┌──────────────────────────────────────────────────────────────────┐     │                      Application Layer (API)                     │     │  - Flask / FastAPI RESTful Backend                                │     │  - Role-Based Access Control (RBAC): Citizen vs. Administrator   │     │  - JWT Authentication & Secure Password Hashing                  │     │  - Hotspot Aggregation & Location Density Engine                 │     └───────────────────────────────────┬──────────────────────────────┘                                         │ SQL / Queries                                         ▼     ┌──────────────────────────────────────────────────────────────────┐     │                        Data Persistence                          │     │  - PostgreSQL / SQLite with Foreign Keys & Cascades              │     │  - Users, Complaints, Pickup Requests Tables                     │     └──────────────────────────────────────────────────────────────────┘ ```  ### Recommended Technology Stack  | Layer | Production Recommendation | Current MVP Implementation | Rationale | | --- | --- | --- | --- | | **Frontend** | Next.js 14 / React with TailwindCSS & Lucide | HTML5 Semantic SPA + Modern CSS + Modular JS | Zero build-step overhead, runs instantaneously on any system, smooth 60fps animations. | | **Backend** | Python (FastAPI / Flask) or Node.js (Express) | Flask 3.1 + Werkzeug + PyJWT | Lightweight, enterprise-tested routing, robust JWT verification, clean JSON serialization. | | **Database** | PostgreSQL (with PostGIS for GIS spatial queries) | SQLite (PostgreSQL compatible schema) | Zero database server setup needed for quick evaluation; Database Schema Design (PostgreSQL / Relational)  ```sql -- 1. Users Table (Citizens and Administrators) CREATE TABLE users (     id SERIAL PRIMARY KEY,     name VARCHAR(120) NOT NULL,     email VARCHAR(180) UNIQUE NOT NULL,     password_hash VARCHAR(255) NOT NULL,     role VARCHAR(20) NOT NULL CHECK (role IN ('Citizen', 'Administrator')) DEFAULT 'Citizen',     phone VARCHAR(30),     address TEXT,     created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP );  CREATE INDEX idx_users_email ON users(email);  -- 2. Complaints / Waste Reports Table CREATE TABLE complaints (     id SERIAL PRIMARY KEY,     user_id INT NOT NULL REFERENCES users(id) ON DELETE CASCADE,     title VARCHAR(200) NOT NULL,     description TEXT NOT NULL,     category VARCHAR(50) NOT NULL CHECK (category IN (         'Overflowing Bins',          'Garbage on Roads',          'Missed Collection',          'Illegal Dumping'     )),     location_text VARCHAR(255) NOT NULL,     latitude DOUBLE PRECISION,     longitude DOUBLE PRECISION,     image_url TEXT,     status VARCHAR(30) NOT NULL CHECK (status IN (         'Pending',          'Assigned',          'In Progress',          'Resolved'     )) DEFAULT 'Pending',     assigned_team VARCHAR(100),     admin_notes TEXT,     created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,     updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP );  CREATE INDEX idx_complaints_status ON complaints(status); CREATE INDEX idx_complaints_location ON complaints(location_text);  -- 3. Bulk / Special Waste Pickup Requests CREATE TABLE pickup_requests (     id SERIAL PRIMARY KEY,     user_id INT NOT NULL REFERENCES users(id) ON DELETE CASCADE,     request_type VARCHAR(100) NOT NULL,     estimated_volume VARCHAR(100) NOT NULL,     waste_type VARCHAR(150) NOT NULL,     pickup_date DATE NOT NULL,     address TEXT NOT NULL,     contact_number VARCHAR(30) NOT NULL,     special_instructions TEXT,     status VARCHAR(30) NOT NULL CHECK (status IN (         'Requested',          'Scheduled',          'Completed',          'Cancelled'     )) DEFAULT 'Requested',     created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP );  CREATE INDEX idx_pickups_date ON pickup_requests(pickup_date); ```  ---  ## 3. Core REST API Endpoints Specification  ### Authentication  - `POST /api/auth/register` &mdash; Registers a new Citizen or Administrator. - `POST /api/auth/login` &mdash; Authenticates credentials and returns JWT token. - `GET /api/auth/me` &mdash; Returns current authenticated profile (requires `Bearer <token>`).  ### Waste Complaints  - `GET /api/complaints` &mdash; Fetch complaints list. Citizens see their own; Admins see all with query filters (`?status=Pending&category=Overflowing Bins`). - `POST /api/complaints` &mdash; Submit a new geotagged complaint (Title, description, category, location, coordinates, photo URL). - `PATCH /api/complaints/:id` &mdash; [Admin Only] Update complaint status (`Pending` &rarr; `Assigned` &rarr; `In Progress` &rarr; `Resolved`), assign field crew, and append resolution remarks.  - `GET /api/pickups` &mdash; Returns scheduled pickups for citizen or administrative overview. - `POST /api/pickups` &mdash; Schedule a dedicated bulk disposal request (Date, estimated volume, material, address). - `PATCH /api/pickups/:id` &mdash; [Admin Only] Change pickup schedule status (`Requested`, `Scheduled`, `Completed`).  ### Admin Analytics & Hotspot Identification  - `GET /api/admin/analytics` &mdash; [Admin Only] Returns:   - KPI Totals: Total complaints, resolved, pending, active, and resolution rate %.   - Hotspots: Locations grouped and sorted by incident frequency.   - Category Distribution: Proportion of complaints per category.  ### Waste Awareness  - `GET /api/awareness` &mdash; Guide data for Biodegradable (Wet), Recyclable (Dry), Domestic Hazardous, and E-Waste streams with segregation rules and disposal tips.  ### EcoAI Assistant & Civic Copilot (AI Assistance Suite)  - `POST /api/ai/chat` &mdash; Natural language AI conversational copilot for disposal rules, complaint guidance, composting advice, and direct navigation triggers. - `POST /api/ai/classify` &mdash; Intelligent issue classifier that analyzes citizen draft observations, assigns optimal category, grades urgency, and drafts standardized municipal dispatch descriptions. - `POST /api/ai/scan` &mdash; EcoAI Vision waste scanner simulation classifying materials, confidence index, recyclability score, and CO2 offset metrics. - `GET /api/ai/route-optimizer` &mdash; [Admin Only] AI transit clustering algorithm optimizing sanitation vehicle routes, incident stop sequences, and fuel savings.  ---  ## 4.
